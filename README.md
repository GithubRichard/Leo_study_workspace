# Leo_study_workspace

用于保存给 Leo 批改作业、错题解析与复习计划的工作目录。所有内容按学科归档，便于回溯「什么时候错的、错在哪、下次盯什么」。

## 目录结构

```
Leo_study_workspace/
├── 语文/
├── 数学/
└── 英语/
    └── 错题周报/
        └── 2026-09-20.md
```

- 一级目录按**学科**划分（语文 / 数学 / 英语），学科的作业批改记录、解析、专项练习都放在对应目录下。
- 每个学科下的 `错题周报/` 存放周期性汇总，文件名以**周报生成日期**命名（`YYYY-MM-DD.md`），一期周报覆盖该周的批改内容。

## 周报内容约定

一份周报通常包含：

1. **本周概览** — 批改份数、错题数、未作答题数、概念问答数
2. **错题明细** — 按练习分页，逐题记录「我的答案 / 正确答案 / 错因」
3. **做得好的题** — 正向反馈，避免只盯着错误
4. **概念问答整理** — 当周提出的疑问及解答（词义、语法、写作素材等）
5. **错误类型归纳** — 把错题归到几类根因（近形词混淆、时态标志词、词性判断等）并统计次数
6. **下周行动清单** — 可勾选的复习任务（补做、默写、专项练习）

核心原则是记录**错因规则**而非仅记录答案，让同类错误在下周被主动盯防。
