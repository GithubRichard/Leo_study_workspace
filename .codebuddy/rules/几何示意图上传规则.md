# 几何示意图上传规则

本规则补充仓库根目录 `README.md` 与 `.codebuddy/skills/leo-study-assistant/SKILL.md` 中“原题照片不上传”的规定；仅对必要的题目示意图开放例外。

## 核心原则

- **原始作业照片、整页试卷、孩子手写作答仍禁止上传 GitHub。**
- 仅当确认错题或存疑题属于**强依赖图形才能理解题意**的题目时，允许把题目中的必要示意图单独裁剪后上传。
- 典型范围：几何图形、几何体示意图，以及确有必要的函数图像、统计图、坐标图等。
- 普通代数题、英语题、纯文字题不上传图片。

## 图片处理要求

1. 只保留理解题意所必需的印刷示意图及必要的印刷标注。
2. 必须尽量排除孩子姓名、学校、班级、手写答案、批改痕迹、二维码、整页试卷及其他无关个人信息。
3. 如果无法在不泄露上述内容的情况下可靠裁出示意图，则不上传，改为在 Markdown 中用文字描述，并注明图片未归档。
4. 不得以“方便”为理由上传整张原图替代裁剪。

## 仓库位置与命名

示意图统一保存到：

`学科/错题示意图/YYYY-MM-DD/`

文件名优先使用可定位的题号，例如：

- `第20题.png`
- `第20题-图1.png`
- `第20题-图2.png`

若同日存在多个来源导致题号重复，在文件名前加入简短来源标识，避免覆盖。

## 与错题记录关联

- 对应的 `学科/错题解析/YYYY-MM-DD.md` 应使用相对路径引用示意图。
- 示例：`![第20题几何示意图](../错题示意图/2026-10-08/第20题.png)`。
- 示意图只作为错题理解辅助，不能替代 Markdown 中的必要题干、条件、孩子原答案、正确答案、解题步骤和错因分析。

## 何时上传

- 默认仅对**确认错题或存疑题**中确实依赖图形的题上传。
- 正确题一般不上传示意图，除非用户明确要求保留。
- 用户明确说“不要上传图片/原图”时，以用户当次要求为最高优先级，本规则不触发。

## Git 与隐私

- 示意图属于经过裁剪的学习记录附件，可以提交、推送到 GitHub；它不是 `学科/原题/` 下的原始资料。
- `学科/原题/` 继续保持 `.gitignore` 保护，原始照片仍只在本地保存。
- 提交前必须再次检查裁剪结果，确认没有把整页原题、手写作答或个人信息一起提交。

## 执行顺序

涉及此类作业时：读取仓库 `README.md` → 读取 `leo-study-assistant/SKILL.md` → 遵循本补充规则 → 首轮批改 → 有确认错题则按规定二次核查 → 主代理复核 → 仅在确有必要时裁剪并上传示意图 → 更新当天错题记录并引用图片 → 自查 → 提交到 GitHub。
