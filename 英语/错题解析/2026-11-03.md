**六、完形填空容易混的7组，放在一起记**

| 易混组 | 怎样区分 | 对比例子 |
|---|---|---|
| look for / find | look for 强调寻找；find 强调找到 | I looked for my key, but I couldn't find it. |
| spend / take | 人＋spend＋时间＋doing；It takes＋人＋时间＋to do | I spent an hour reading. / It took me an hour to read the story. |
| borrow / lend / keep | borrow 借入；lend 借出；keep 可表示借用并保留一段时间 | borrow a book from Tom / lend a book to Tom / keep it for a week |
| say / tell / speak / talk | say 看内容；tell 常接人；speak 常接语言；talk 常用于交谈 | say hello / tell me a story / speak English / talk with friends |
| stop doing / stop to do | 停止正在做的事／停下来去做另一件事 | stop talking 停止说话 / stop to rest 停下来休息 |
| remember doing / remember to do | 记得做过／记得要做 | remember locking the door / remember to lock the door |
| because / because of | 后接完整句子／后接名词短语 | because it rained / because of the rain |

**七、结合孩子之前的错题，再补5个重点**

| 搭配／结构 | 要记住的点 |
|---|---|
| ★respond to sth | 对……作出回应：respond to a question；不要漏 to。 |
| prefer A to B | 比起B更喜欢A：prefer tea to coffee；动词形式可用 prefer doing A to doing B。 |
| see sb doing / see sb do | 看到某人正在做／看到动作发生或全过程；具体选哪个要看语境。 |
| make sb do / make sb＋形容词 | make me laugh；make me happy。主动结构中不能写 make me to laugh。 |
| have fun doing | 做……很开心：have fun playing games；fun 是不可数名词。 |

**孩子做题时，按这3步判断**

1. **先读意思：**这句话是在讲“寻找”，还是“已经找到”？是在讲“照顾”，还是“调查”？
2. **再看结构：**空格后面是人、名词、doing，还是 to do？例如 thank you **for helping** me。
3. **最后看全文：**即使搭配正确，也要符合人物行为、前后因果和故事时态。不能看到熟悉词组就马上选。

## 概念问答：ended up是什么意思

ended up是end up的过去式，表示最后／结果……，强调最终到了某种处境或产生某种结果，常与原计划不同，但不一定意外或负面。不能只翻译为结束。

关联前次综合复测第30题：I ordered soup but ended up with a plate of noodles by mistake. 我点了汤，结果却因为弄错了，得到了一盘面条。with后接最终得到／拥有的东西。

常用结构：end up doing（最后做了……），We wanted to go out, but ended up staying at home.；end up with＋名词（最后得到／带着……），end up with a plate of noodles；end up as＋身份（最后成为……），He ended up as a teacher.。不要写end up to do；ended up是过去式，doing仍按结构使用，不变为stayed。
