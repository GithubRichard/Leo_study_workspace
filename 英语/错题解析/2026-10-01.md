## 逐题解析

### A-单项选择第5题
- 题干：Her rough voice needs ___ well.
- 孩子答案：B. to hear
- 正确答案：C. hearing
- 规则：`need doing` 可表示“需要被……”，主动形式表达被动意义；这里声音“需要被听清/听到”，所以用 `needs hearing`。
- 状态：待订正、待复测。

### A-完成句子第3题
- 题意：她不需要觉得不开心。
- 孩子答案：She don't need to feel unhappy.
- 正确答案：She doesn't need to feel unhappy.
- 错因：主语是第三人称单数 `She`，一般现在时否定助动词用 `doesn't`。
- 状态：待订正、待复测。

### A-完成句子第5题
- 题意：这个节目需要被收听。
- 孩子答案：The program need listen to.
- 参考答案：The program needs listening to. / The program needs to be listened to.
- 错因：一是主语 `The program` 为单数，谓语要用 `needs`；二是“需要被收听”应用 `need doing` 或 `need to be done`。
- 状态：待订正、待复测。

### B-单项选择第4题
- 题干：These nice papers need ___.
- 孩子答案：B. to cut
- 正确答案：C. cutting
- 错因：纸是“被剪”，用 `need cutting` 表示“需要被剪”。
- 状态：待订正、待复测。

### B-完成句子第2题
- 题意：Nina需要为项目筹钱。
- 孩子答案：Nina need to collect money.
- 正确答案：Nina needs to collect money.
- 错因：第三人称单数 `Nina` 后 `need` 要加 `-s`。
- 状态：待订正、待复测。

- 错因：助动词 `does` 拼写错误。
- 状态：待订正、待复测。

### C-第一大题第5题
- 题干：The football uniform needs ___ (wash) now.
- 孩子答案：to wash
- 正确答案：washing / to be washed
- 错因：球衣是“被洗”，不能用主动的 `to wash`；应用 `need doing` 或 `need to be done`。
- 状态：待订正、待复测。

### C-句型转换第3题

- 错因：同义转换时漏掉否定意义；`needn't = don't/doesn't need to`。

### E-根据中文完成句子第9题

- 正确答案：The ship sank quickly after hitting the iceberg.

### E-根据中文完成句子第10题
- 题意：他深吸了一口气，然后走进了办公室。

- 正确答案：He took a deep breath and then entered the office.
- 错因：与后面的 `entered` 时态一致，`take` 应使用过去式 `took`。
- 状态：待订正、待复测。

### E-句型转换第5题
- 题干：He is getting ready for the coming exam.（改为同义句）

- 正确答案：He is preparing for the coming exam.
- 错因：`get ready for = prepare for`；`prepare to do` 后面接动词原形，不能接名词 `the coming exam`。
- 状态：待订正、待复测。

- 错因：`was + 过去分词` 构成被动/状态表达；`break-broke-broken`，此处用 `broken`。
- 状态：待订正、待复测。

## 当日重点
1. **最高优先级：need 的两套结构**
   - 人主动做事：`need to do`
   - 事物需要被处理：`need doing = need to be done`
2. **第三人称单数**：`She/Nina/The program/The problem + needs/doesn't`。
3. **不规则过去式/过去分词**：`sink-sank-sunk`、`take-took-taken`、`break-broke-broken`。
4. **固定搭配**：`prepare for + 名词`；`prepare to do sth.`。
5. 建议复习10—15分钟：先把以上15处错题订正一遍，再重点口头造句3组 `need doing` 与 `need to do` 对比句，隔1—2天复测。
