## 确认错题逐题解析

### 第13题：电影过去常被放映
题干：The film made by Walt Disney ___ all over the world.

选项：A. is used to show   B. is used to showing   C. used to show   D. used to be shown

孩子原答案：B. is used to showing；参考答案：D. used to be shown。

正确推理：先找主语The film。made by Walt Disney只是修饰film，表示沃尔特·迪士尼制作的电影，不是本句谓语。电影是被放映，不是自己放映，因此需要被动结构be shown；选项中D used to be shown表示过去常被放映，结构与意思都成立。

孩子误选及逐项辨析：B的be used to doing表示习惯于做某事，会变成电影习惯于放映，既不符合主语含义，也没表达被动。A的be used to do表示被用来做某事；is used to show单独放在这里缺少show所展示的对象，不能表达电影被放映。C used to show是过去常主动展示/放映，没有被动的be shown。

迁移判断：先定含义（过去常常/习惯于/被用来），再看动作方向（电影被放映）。例如：People used to show the film. → The film used to be shown.

订正与复测：待订正、待复测；错误规则依据句子，不推测孩子心理原因。

### 第16题：现在的睡前习惯
题干：- What do you usually do before going to bed? - I ___.

选项：A. used to write diaries   B. am used to sleeping   C. am used to reading

孩子原答案：A. used to write diaries；参考答案：C. am used to reading（按照片可见选项）。

正确推理：问题的do you usually do问现在通常做什么。A used to write diaries说过去常写日记，时间不对应。C I am used to reading表达现在习惯阅读，与睡前活动相符；更直接自然的开放式回答是I usually read before going to bed.，但题目要求从选项中选择，因此选C。

孩子误选及逐项辨析：B I am used to sleeping虽然语法形式成立，却是习惯睡觉，无法合理回答睡觉前做什么。C be used to中的to是介词，后接reading；A used to中的to属于不定式结构，后接write，两者不能只凭to就混选。

迁移判断：先圈时间：usually询问现在习惯，used to描述过去。比较I used to read before bed.（过去常读）与I am used to reading before bed.（现在习惯读）。

订正与复测：待订正、待复测；错误规则依据句子，不推测孩子心理原因。

## 当日重点
|结构|意思|示例|
|---|---|---|
|used to do|过去常常做|He used to walk.|
|be used to doing / 名词|习惯于做/某事|He is used to walking.|
|be used to do|被用来做|A camera is used to take photos.|
|used to be done|过去常被……|The film used to be shown.|

判断顺序：先读句意和时间，再判断主动被动，最后检查动词形式。注意be used to doing可以用于不同时间（is/was），不能笼统说它只能表示现在。

## 第13题概念问答：中文没有被字是否仍需被动
用户问可否译为迪士尼制作的电影常常在世界各地放映。解释：中文这样表达可以理解；选择D后的完整时间含义应补过去，译为这部迪士尼制作的电影过去常在世界各地放映。中文可省被字，英语仍需根据具体结构表达电影是动作接受者，不能因中文无被字就选主动形式。若只表达现在常常放映，可写The film is often shown all over the world.；过去常放映则The film used to be shown all over the world.；B is used to showing表示习惯于做，不能把is used to当often常常。此为原错题释义补充，不是新错题或复测，不改变统计，不另生成PDF；无需新增二次核查。

## 第13题继续问答：A与D的被动到底落在哪个动词
澄清：show可以表示展示、放映，shown只是其过去分词，并非show只能译展示而shown只能译放映。A is used to show拆为[is used]被使用+[to show]来展示/放映，被动落在use上；例如A projector is used to show films（放映机被用来放电影）。D used to be shown拆为[used to]过去常常+[be shown]被放映，被动落在show上。口诀：A被使用，D被放映。先前仅给不同中文词义可能造成误解，本节补充明确，题目结论与统计不变。无新作答，不新增错题、PDF或二次核查。
